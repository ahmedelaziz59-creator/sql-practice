# SQL Practice

Interview-style SQL exercises for junior data analyst roles, using small sample e-commerce tables (customers, orders, products, order_items).

## What's inside

`queries.sql` has the sample data and six exercises. Each one lists the question, the concepts used, my query, and the expected result.

| # | Exercise | Concepts |
|---|---|---|
| 1 | Top 3 customers by spend | JOIN, WHERE, GROUP BY, SUM, LIMIT |
| 2 | Products that were never sold | LEFT JOIN, IS NULL |
| 3 | Total quantity sold per product | JOIN, SUM, GROUP BY |
| 4 | Customers with a high total | HAVING |
| 5 | Top 2 countries by revenue | JOIN, GROUP BY, ORDER BY |
| 6 | Customers who never ordered | LEFT JOIN, IS NULL |

## How to run it

Paste the file into any SQL tool that supports SQLite or PostgreSQL, such as DB Browser for SQLite, and run it from the top.
